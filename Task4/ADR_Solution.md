#### Архитектурные решения

**1. Централизованное управление ставками в АБС**
- Замена Excel-файлов на модуль управления ставками
- Единый источник истины для всех депозитных ставок
- Автоматическое распространение изменений во все каналы

**2. Гибридная модель интеграции**
- REST API для внутренней системы кол-центра (синхронная интеграция)
- SFTP файловый обмен для партнерского кол-центра (асинхронная интеграция)
- Поддержка разных протоколов под потребности каждой системы

**3. Кэширование для производительности**
- Redis кэш в системе кол-центра для быстрого доступа к ставкам
- Минимизация нагрузки на АБС при частых запросах
- Автоматическое обновление кэша при изменении ставок

**4. Автоматизация процессов**
- Автоматическая генерация и размещение файлов на SFTP
- Уведомления об успешных/неуспешных операциях

**5. Безопасность и надежность**
- SSH-ключи для аутентификации на SFTP
- Версионирование файлов ставок
- Полное логирование всех операций передачи данных

### **Альтернативы**

**1. Единая API интеграция для всех кол-центров**
Недостатки:
- Партнерский кол-центр не готов к API интеграции
- Сложности с обеспечением безопасности внешних подключений

**2. Только файловый обмен через SFTP**
Недостатки:
- Задержки в получении актуальных данных внутренним кол-центром
- Усложнение архитектуры внутренних систем
- Необходимость дополнительной обработки файлов

**3. Ручная передача данных**
Недостатки:
- Высокий риск человеческих ошибок
- Задержки в актуализации данных
- Неэффективное использование ресурсов персонала

### **Недостатки, ограничения, риски**

**Недостатки:**
- Усложнение интеграционной архитектуры из-за поддержки двух протоколов
- Дополнительная нагрузка на инфраструктуру

**Ограничения:**
- Партнерский кол-центр может получать только файлы, без API
- Зависимость от стабильности SFTP-соединения
- Ограничения формата файлов под требования партнера

**Риски:**
- Рассинхронизация данных между системами
- Сбои в автоматической передаче файлов через SFTP
- Перегрузка АБС при частых запросах актуализации ставок
- Проблемы доступности SFTP-сервера для партнера
- Задержки в обновлении ставок из-за сетевых проблем
